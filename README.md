# The Forgotten Forest

An atmospheric multiplayer survival-adventure game for 8–12 players per Roblox server.

Explorers establish a Safe Haven at the edge of a mysterious forest, gather resources, craft tools, investigate abandoned places, uncover ancient secrets, and survive increasingly dangerous nights.
